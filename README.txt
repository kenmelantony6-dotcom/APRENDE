# APRENDE+ — versión para teléfono

Esta carpeta contiene una versión PWA de APRENDE+.

Incluye:
- Nombre del estudiante
- 9 materias
- Niveles Fácil, Medio y Difícil
- Preguntas de opción múltiple
- Puntuación
- Resultados
- Guardado local del nombre y progreso
- Diseño adaptable a Android

Para instalarla como app:
1. Publica esta carpeta en un sitio HTTPS (por ejemplo, un servicio de páginas web).
2. Abre la dirección desde Chrome en Android.
3. Usa "Añadir a pantalla de inicio" / "Instalar aplicación".

Nota: abrir index.html directamente permite probar la interfaz, pero algunas funciones PWA (instalación y service worker) requieren HTTPS o localhost.
